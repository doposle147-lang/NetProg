# NetProg

Репозиторий для выполнения практической работы № 3 по дисциплине «Технологии и методы программирования» (ТиМП).
Тема: «Технологии сетевого взаимодействия в программах».

## Структура проекта

```text
NetProg/
├── .gitignore
├── README.md
├── daytime/
│   ├── .gitignore
│   ├── Makefile
│   └── daytime.cpp
└── echo/
    ├── .gitignore
    ├── Makefile
    └── echo.cpp
```

## Описание компонентов

1. **daytime/** — клиент сетевой службы daytime по протоколу UDP (RFC 867).
   - Клиент отправляет дейтаграмму на сервер и получает в ответ строку с текущей датой и временем.
   - По умолчанию используется порт 13 (UDP).
   - Сборка: `make` в каталоге `daytime/`.
   - Запуск на сервере кафедры: `./daytime_client 172.16.40.1 13`
   - Запуск для локального тестирования: `./daytime_client 127.0.0.1 8013`

2. **echo/** — клиент сетевой службы echo по протоколу TCP (RFC 862).
   - Клиент устанавливает надёжное TCP-соединение с сервером, отправляет строки текста и отображает полученное эхо.
   - По умолчанию используется порт 7 (TCP).
   - Сборка: `make` в каталоге `echo/`.
   - Запуск на сервере кафедры: `./echo_client 172.16.40.1 7`
   - Запуск для локального тестирования: `./echo_client 127.0.0.1 8011`

## Сборка и очистка

```bash
# Сборка клиента daytime
cd daytime
make
./daytime_client 172.16.40.1 13
make clean

# Сборка клиента echo
cd ../echo
make
./echo_client 172.16.40.1 7
make clean
```
